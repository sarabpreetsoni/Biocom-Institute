# Biocom Institute — Commerce Learning Portal
*Free education to all*

A modern React & TypeScript educational web application for students and administrators with assignment sharing, study materials, and student management.

---

## Features

- **Portals**:
  - **Student Portal**: Subject selection (Accountancy, Business Studies, Economics, Practical & Projects), assignment lists, and document downloading.
  - **Admin Portal**: Coursework publication, file uploading, assignment deletion, and enrolled student roster.
- **Tech Stack**:
  - React 18
  - TypeScript
  - Tailwind CSS
  - Vite
  - Lucide Icons
  - Local state & persistence storage service

---

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## Deployment to Vercel

```bash
npm run deploy:vercel
```
Or push your changes to GitHub to trigger automatic deployment on Vercel.
